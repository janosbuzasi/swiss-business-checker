# Swiss Business Checker

A lightweight PHP tool to check Swiss business name candidates against:

- `.ch` domain availability hints
- Swissreg trade mark search
- live ZEFIX PublicREST company register results
- JSON API output

## Current UI

The interface follows the shared webtrash.ch tool style:

- WT branding in the header
- burger-menu navigation
- consistent layout with the other tools

## Notes

The project is intentionally simple and runs on basic PHP hosting without a database.
